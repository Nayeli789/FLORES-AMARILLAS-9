# 🌼 Árbol de flores amarillas

Proyecto web inspirado en el efecto del video: árbol, flores amarillas formando un corazón, pétalos, fondo nocturno, mensaje y contador.

## Lo que necesitas

Para EDITARLO en Android:
- Acode, Spck Editor o cualquier editor de HTML.

Para VERLO:
- Chrome, Edge, Firefox o cualquier navegador moderno.
- La otra persona NO necesita instalar un editor de código.

## Cómo abrirlo

1. Descomprime el ZIP.
2. Abre `index.html` con un navegador.
3. Para personalizarlo, abre `script.js`.

## Personalización rápida

En `script.js` cambia:

const NOMBRE = "Mi persona especial";

const FECHA_INICIO = "2025-09-07T00:00:00";

const MENSAJE = "Tu mensaje...";

La fecha usa el formato:
AAAA-MM-DDTHH:MM:SS

## Para enviárselo a otra persona

La forma más cómoda es publicarlo como una página web (por ejemplo con GitHub Pages o Netlify) y enviarle el enlace. Así la otra persona solo toca el enlace y se abre en Chrome; no necesita instalar nada.

Si envías solamente `index.html` como archivo, puede funcionar al abrirlo localmente, pero compartirlo como enlace web es mucho más cómodo.
